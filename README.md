# 車藍牙自動開 (CarLaunch)

手機連上指定的藍牙裝置（例如車子）時，自動依序開啟你選的 App。

## 下載
最新版 APK：到本 repo 的 **Releases** → 下載 `CarLaunch.apk`
（直連：`/releases/latest/download/CarLaunch.apk`）

## 使用
1. 開 App → 授權「藍牙」與「顯示在其他應用程式上層」
2. 「＋ 新增藍牙裝置」→ 選你的車（要先在系統設定配對過）
3. 勾選要開的 App，勾選順序就是開啟順序，最後一個停在最前面
4. 按「測試」確認，之後上車連上藍牙就會自動開

小米 / OPPO / vivo / 華為：另外到 App 資訊開「自啟動」、「背景彈出視窗」，電池設「無限制」。

## 原理
- 系統廣播 `ACL_CONNECTED`（藍牙連上）→ `BtReceiver` 比對裝置 → `AppLauncher` 依序開啟
- 同一台裝置 2 分鐘內重複連線不重開
- 斷開藍牙 15 秒後仍沒連回來 → 暫停音樂、回到桌面（Android 不允許一般 App 強制關閉其他 App）
- App 被關掉也會觸發（除非在設定裡「強制停止」）
